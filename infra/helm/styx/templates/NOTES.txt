To access Styx, set up port-forwards:

  # AI API Gateway (drop-in OpenAI replacement)
  kubectl port-forward svc/{{ include "styx.fullname" . }}-router {{ .Values.router.service.port }}:{{ .Values.router.service.port }}

  # Dashboard
  kubectl port-forward svc/{{ include "styx.fullname" . }}-dashboard {{ .Values.dashboard.service.port }}:{{ .Values.dashboard.service.port }}

  # Backend API
  kubectl port-forward svc/{{ include "styx.fullname" . }}-backend {{ .Values.backend.service.port }}:{{ .Values.backend.service.port }}

Then:
  - Dashboard  → http://localhost:{{ .Values.dashboard.service.port }}
  - API calls  → http://localhost:{{ .Values.router.service.port }}/v1/chat/completions
{{- end }}

Quick test:
  curl http://localhost:{{ .Values.router.service.port }}/health

To check all pods:
  kubectl get pods -l app.kubernetes.io/part-of=styx
